🚀 VoyagePlanner: Space Tourism Booking Application

🌌 Project Overview

This project elevates the existing static Space Tourism website into a fully interactive, dynamic booking application. The core objective was to implement modern, front-end reservation management (CRUD operations) and user authentication using Vanilla JavaScript (ES6+) while strictly adhering to the original high-fidelity design aesthetic.

5 days, no dependencies, pure JS magic. We call it "The Frontend Gauntlet."

✨ Key Features

1. 🎫 Dynamic Reservation System

Intelligent Forms: Adaptive booking form with fields that update contextually based on user selection.

Real-Time Pricing: Immediate calculation and display of the total mission price based on destination, duration, and passenger count.

Data Integrity: Robust, client-side validation using Regular Expressions (RegEx) to ensure data consistency and provide clear user feedback.

2. 🔐 Authentication & Session Management

Simulated Login: Simple but persistent session management using localStorage to handle logged-in state.

UI Adaptation: Seamless interface management (e.g., showing a "My Bookings" link instead of "Login") for authenticated users.

3. 🗂️ CRUD Data & Booking Management

Full Lifecycle: Complete management of the reservation process: Creation, Consultation, Modification, and Deletion.

Centralized Dashboard: A dedicated interface for reservation administration, featuring advanced search and filtering based on multiple criteria.

Local Persistence: All reservation data is securely backed up in the browser's localStorage with unique identifiers.

4. 🖨️ Improved User Experience & Deliverables

Mobile-First Design: The application is fully responsive and fluid across all devices, prioritizing the mobile experience.

Accessibility (A11y): Compliance with accessibility standards and optimization for high performance.

Ticket Generation: Professional, print-optimized ticket templates utilizing native browser printing functionality.
